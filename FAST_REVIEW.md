## Section 2 — Agentic foundations

- workflow: developer-authored control flow
- agent: runtime/model-driven decisions
- agentic loop: perceive → reason → act → observe
- `tool_use` → runtime execution → `tool_result`
- hard limits belong in runtime
- retry only when progress is possible
- escalation is a designed safety path
- simple-first: use workflow unless autonomy earns its complexity
